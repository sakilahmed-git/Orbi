# Scintilla visual palette

The interface uses one shared signal system: blue indicates the event/present or improved state; orange indicates the frame-camera, absent, baseline, or warning state. Green/red success/failure colors are intentionally not used.

- `ink` — `#0A0E14`: page background
- `surface` — `#10151F`: panels and inputs
- `line` — `#273247`: panel boundaries and chart grid
- `text` — `#E7ECF4`: primary copy
- `signal-blue` — `#4FA6FF`: event OFF polarity, successful/present states, armed controller
- `signal-orange` — `#FF6A3D`: event ON polarity, baseline/absent states, warnings
